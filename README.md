# WWEcho 声骸工作台

WWEcho 是一个用于《鸣潮》声骸评分、开孔推荐、频整器计算的桌面应用。通过图形界面选择声骸词条、调整评分权重，并查看培养建议和频整器洗炼收益。

> 本应用的评分权重可自行调整。培养成本中的经验、打孔器消耗与回收比例按项目配置和用户提供的数据建模，不代表官方推荐、精确体力成本或游戏内保证结果。

## 功能介绍

### 核心功能1:声骸评分

- 选择 Cost 1、3 或 4，查看相应主词条及五星 +25 满级数值，固定小词条随 Cost 自动确定。
- 选择 0～5 个不同副词条，并为每条设置档位。
- 分数随词条、档位或权重变化即时更新，并显示词条贡献与目标分数进度。

### 核心功能2:调频（开孔）培养建议

- 根据目标分数评估开孔后达标的概率，并比较继续培养与弃置重开的平均累计成本。
- 基于达标概率+累计成本，进行开孔推荐
- 可根据个人资源储备调整经验、打孔器和胚子的相对成本权重，以及弃置回收比例。
- 计算结果是当前概率网格和成本假设下的估算。

### 核心功能3:频整器洗炼分析

- 五条副词条开满后，可锁定 1～4 条并分析其余词条重构后的升分概率与收益。
- 比较给定预算下的指定锁法和动态换锁方案（动态方案可根据每次重构后的实际状态重新选择后续锁法）。给定预算支持 0～6 枚。

### 权重方案管理

- 可以按副词条、Cost 1/3/4 主词条和固定小词条，分别设置权重。
- 【!!】不同的权重会影响评分计算和推荐结果。
- 修改后可保存当前方案或另存为新方案，也可重命名、删除和切换方案。
- 区域 1 标题右侧以不加粗的小字显示当前权重方案名，折叠后标注变为蓝色。
- 支持导出全部方案进行分享，导入时可以按方案 ID 去重。
- 方案数据保存在所在目录的 `weight-presets.json`

## 安装与启动

### 使用独立应用

Release提供了 Windows `.exe` 或 macOS `.app`，可直接运行，无需在目标电脑安装 Python：

- Windows：双击 `WWEcho声骸工作台.exe` 启动。
- macOS：在 Finder 中将 `WWEcho声骸工作台.app` 放到可写入的普通文件夹后打开。当前构建未进行 Apple Developer ID 签名和公证，macOS 可能显示安全提示。

首次启动会在应用所在目录创建权重方案库`weight-presets.json`；备份该文件即可保留自己的方案。

### 从源码运行

需要 Python 3.9 或更高版本。

Windows 可在项目目录双击 `run.bat`：脚本会创建项目虚拟环境并安装运行依赖（首次运行需要网络）。

macOS/Linux 用户在项目目录执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./run.sh
```

`run.sh` 使用项目 `.venv` 中的 Python；若尚未安装依赖，请先执行上面的安装命令。

### 自行构建应用

构建需要 Python 3.9 或更高版本及网络连接：

- Windows：在 Windows 上双击 `build-windows.bat`，生成 `dist/WWEcho声骸工作台.exe`。
- macOS：在 macOS 项目目录执行 `./build-macos.sh`，生成 `dist/WWEcho声骸工作台.app`。应用架构与构建机的 Python 架构一致，例如 Apple Silicon 上构建得到 arm64 应用。

构建脚本会安装 `requirements-build.txt` 中的 PyInstaller 依赖。Windows 与 macOS 应分别在对应系统上构建。

macOS 构建前，项目根目录需有有效的 `weight-presets.json` 作为初始方案库模板；缺失时可先运行源码版 GUI 创建，或从已有方案库复制到该位置。

## 使用说明

1. **选择权重方案**：在顶部下拉框切换方案。可直接编辑权重；“保存修改”将修改保存到当前方案，“另存为”将保存到新方案。也可在“管理”菜单中重命名、删除方案。“导入”或“导出”方案能够自动去重。
2. **录入声骸和查看评分**：选择 Cost，再选择主词条；点击副词条名称勾选或取消，并在旁边选择档位。评分将会实时更新。
3. **开孔培养建议**：设置目标分数和材料成本参数。继续培养或弃置重开的建议会随着评分实时更新。
4. **频整器洗炼分析**：开满五条副词条后，在区域 4 锁定希望保留的词条，可以查看当前锁定下的概率和收益。也可以在方案表中点击想要的锁法，查看概率和收益。也可以设置频整器预算查看同预算下的方案收益。

关闭窗口或切换权重方案时，若当前方案有未保存修改，可选择保存、放弃或取消操作。建议定期将权重方案导出备份。

## 配置与更多资料

- `config/score-weights.json`：初始默认评分权重。
- `config/echo-stats.json`：词条定义、满级值、档位及概率数据。
- `config/activation-costs.json`：培养经验、打孔器消耗、回收规则和默认成本权重。

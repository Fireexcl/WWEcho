# 声骸评分原型

评分核心使用 Python 标准库，无第三方运行依赖；独立窗口使用 PySide6，依赖见 [requirements.txt](requirements.txt)。当前代码兼容 Python 3.9+；新环境建议使用 Python 3.12。计算入口在 [echo_score.py](echo_score.py)，窗口入口在 [echo_gui.py](echo_gui.py)。

## 独立窗口 GUI

安装 GUI 依赖后使用 Python 启动 [echo_gui.py](echo_gui.py)，或在 VS Code 运行“启动声骸评分 GUI”任务。窗口分为三个区域：

1. **上方权重配置**：主、副词条权重分标签页展示，可以直接编辑、导入/导出 JSON 预设、恢复默认占位权重。支持 0～1000000 的权重和最多四位小数。修改不会自动覆盖内置配置；需要保留时请导出，下次打开后导入。
2. **中间词条选择**：选择 1/3/4 Cost，主词条候选随 Cost 更新并显示 +25 满级值；选择已激活副词条数量（1～5），每行选择词条及合法数值档位。未激活行禁用；重复类型提示错误并清除旧结果。
3. **下方目标与结果**：设置目标分数，显示当前总分、主副词条分项、距目标差值、目标完成进度及贡献明细。所有输入修改后实时计算，也可点击计算按钮。

目标仅用于比较当前得分，不代表后续成功概率。此版不计算调谐成本或继续建议。独立窗口支持 macOS/Windows；尚未打包为 Windows EXE。

界面仅依赖 PySide6 的 Essentials（Qt Widgets/Core/Gui），不安装此版未使用的大型 Addons 模块。

## 评分规则

按用户要求，计入**五星 +25 主词条和已激活的 1～5 条副词条**，不计固定小词条、未激活槽位或套装效果。

$$
S = w_{\mathrm{main}} + \sum_{i\in A} w_i\frac{x_i}{r_i}
$$

- 主词条参考值为该 Cost 的满级值，输入必须满级，因此贡献为主词条权重。
- 副词条参考值为 [属性配置](config/echo-stats.json) 中对应类型的最高档位。
- 权重表示一个参考满档词条的分值。主、副词条分别配置，同名主副词条可以同时计分。
- 未激活槽位贡献为 0；不按当前激活数量平均，也不转换为百分制。不同 Cost、主词条或预设之间的分数可比性由用户配置决定。
- 不按概率、稀有程度计分，分数不代表实际伤害提升百分比。

## 权重

修改 [config/score-weights.json](config/score-weights.json) 中的 `main_stats` 和 `sub_stats`，也可通过命令行 `--weights` 指定自己的配置。所有字段必须完整，权重为非负有限数值，无效属性可设为 0。

当前为**占位数值**：各主词条 20 分；副词条双暴各 20 分、攻击百分比/共鸣效率/四类伤害加成各 10 分、固定攻击 5 分、生命/防御类 0 分。不是官方推荐或任何角色的真实收益权重。

## 输入及使用

输入格式见 [examples/echo.json](examples/echo.json)：

- `main_stat`：一个包含 `name`、`value` 的词条对象。
- `sub_stats`：包含 1～5 个词条对象的数组。
- `cost`：可选整数 1、3、4；提供时按指定 Cost 校验，否则根据主词条名和满级数值验证候选，不强行推断唯一 Cost。
- `name` 支持配置中的准确中文名或统一英文标识；例如“固定攻击”和 `atk_flat`，不接受含糊的“攻击”。
- `value` 使用 JSON 数字；百分比用百分点，例如 10.5 表示 10.5%，不能输入 0.105 或字符串“10.5%”。
- 副词条必须为实际离散档位，副词条之间不可重复；允许与主词条同名。

在项目目录执行 Python 脚本并传入示例 JSON 路径，默认只输出分数；追加 `--details` 输出贡献明细。省略输入路径时从标准输入读取 JSON。默认配置路径相对程序位置解析，不依赖运行目录。

Python 接口：`EchoScorer.from_files().score(echo)`，返回含 `score`、`main_score`、`sub_score` 和词条贡献明细的字典。

示例的结果为 **90 分**：主词条 20 分、副词条 70 分。若仅保留第一条满档暴击率副词条，则为 **40 分**。

非法输入在 API 中抛出 `ValueError`；命令行将错误写入标准错误并以状态码 2 退出。

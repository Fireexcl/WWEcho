# WWEcho 声骸工作台

WWEcho 是一个用于《鸣潮》五星声骸评分与培养分析的桌面应用。通过图形界面选择声骸词条、调整评分权重，并查看培养建议和频整器洗炼收益；不需要手动准备声骸 JSON 输入文件。

> 本应用的评分权重可自行调整。培养成本中的经验、打孔器消耗与回收比例按项目配置和用户提供的数据建模，不代表官方推荐、精确体力成本或游戏内保证结果。

## 功能介绍

### 声骸评分

- 选择 Cost 1、3 或 4，查看相应主词条及五星 +25 满级数值。
- 选择 0～5 个不同副词条，并为每条设置档位；副词条可与主词条同名。
- 固定小词条随 Cost 自动确定，不需要手动输入。
- 分数随词条、档位或权重变化即时更新，并显示词条贡献与目标分数进度。

### 权重方案

- 按副词条、Cost 1/3/4 主词条和固定小词条分别设置权重；数值可设为 0。
- 修改后可保存当前方案或另存为新方案，也可重命名、删除和切换方案。
- 支持导出全部方案，以及按方案 ID 去重后追加导入；导入不会覆盖本地同 ID 方案。
- 方案数据保存在应用旁边的 `weight-presets.json`，便于备份和迁移。

### 调频／开孔培养建议

- 根据目标分数评估开孔后达标的概率，并比较继续培养与弃置重开的平均累计成本。
- 可调整经验、打孔器的弃置回收比例，以及经验、打孔器和胚子的相对成本权重。
- 成品口径要求达标后仍升至 +25 并开满五条；达标后不再弃置，剩余培养消耗计入成本。
- 计算结果是当前概率网格和成本假设下的估算，不是固定预算内的成功保证。

### 频整器洗炼分析

- 五条副词条开满后，可锁定 1～4 条并分析其余词条重构后的升分概率与收益。
- 比较不同预算下的固定锁法和动态换锁方案；动态方案可根据每次重构后的实际状态重新选择后续锁法。
- 频整器消耗按锁定条数分别为 1、1、2、3 枚；区域预算支持 0～6 枚。

## 安装与启动

### 使用独立应用

如果发布包提供了 Windows `.exe` 或 macOS `.app`，可直接运行，无需在目标电脑安装 Python：

- Windows：双击 `WWEcho声骸工作台.exe`。
- macOS：在 Finder 中将 `WWEcho声骸工作台.app` 放到可写入的普通文件夹后打开。当前构建未进行 Apple Developer ID 签名和公证，macOS 可能显示安全提示；仅在信任来源时允许打开。

请将 `weight-presets.json` 与应用放在约定位置并保持可写：Windows 放在 EXE 旁，macOS 放在 `.app` 同级目录。首次启动会在该位置创建方案库；升级时保留该文件即可保留自己的方案。

### 从源码运行

需要 Python 3.9 或更高版本。Windows 可在项目目录双击 `run.bat`：脚本会创建项目虚拟环境并安装运行依赖（首次运行需要网络）。

macOS/Linux 用户在项目目录执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./run.sh
```

`run.sh` 使用项目 `.venv` 中的 Python；若尚未安装依赖，请先执行上面的安装命令。

### 自行构建应用

构建需要 Python 3.9 或更高版本及网络连接：

- Windows：在 Windows 上双击 `build-windows.bat`，生成 `dist/WWEcho声骸工作台.exe`。
- macOS：在 macOS 项目目录执行 `./build-macos.sh`，生成 `dist/WWEcho声骸工作台.app`。应用架构与构建机的 Python 架构一致，例如 Apple Silicon 上构建得到 arm64 应用。

构建脚本会安装 `requirements-build.txt` 中的 PyInstaller 依赖。Windows 与 macOS 应分别在对应系统上构建。

macOS 构建前，项目根目录需有有效的 `weight-presets.json` 作为初始方案库模板；缺失时可先运行源码版 GUI 创建，或从已有方案库复制到该位置。

## 使用说明

1. **选择权重方案**：在顶部下拉框切换方案。可直接编辑权重；“保存修改”保存到当前方案，“另存为”创建独立方案。也可在“管理”菜单中重命名、删除、导入或导出方案。
2. **录入声骸**：选择 Cost，再选择主词条；点击副词条名称勾选或取消，并在旁边选择档位。应用会自动显示满级主词条和对应 Cost 的固定小词条。
3. **查看评分与培养建议**：设置目标分数和材料成本参数。评分立即更新，培养策略在后台计算；成本参数影响继续培养或弃置重开的比较结果。
4. **分析频整器洗炼**：开满五条副词条后，在区域 4 锁定希望保留的词条，设置频整器预算并查看单次及同预算动态方案。

关闭窗口或切换方案时，若当前方案有未保存修改，可选择保存、放弃或取消操作。建议定期将权重方案导出备份。

## 配置与更多资料

- `config/score-weights.json`：初始默认评分权重。
- `config/echo-stats.json`：词条定义、满级值、档位及概率数据。
- `config/activation-costs.json`：培养经验、打孔器消耗、回收规则和默认成本权重。

# WWEcho 声骸工作台

WWEcho 是一个用于《鸣潮》声骸评分、开孔推荐、频整器计算的桌面应用。通过图形界面选择声骸词条、调整评分权重，并查看培养建议和频整器洗炼收益。

> 本应用的评分权重可自行调整。培养成本中的经验、打孔器消耗与回收比例按项目配置和用户提供的数据建模，不代表官方推荐、精确体力成本或游戏内保证结果。

## 功能介绍

### 核心功能1:声骸评分

- 选择 Cost 1、3 或 4，查看相应主词条及五星 +25 满级数值，固定小词条随 Cost 自动确定。
- 选择 0～5 个不同副词条，并为每条设置档位。
- 分数随词条、档位或权重变化即时更新，并显示词条贡献与目标分数进度。

### 核心功能2:调频（开孔）培养建议

- 根据目标分数评估开孔后达标的概率，并比较继续培养与弃置重开的平均累计成本。
- 基于达标概率+累计成本，进行开孔推荐
- 可根据个人资源储备调整经验、打孔器和胚子的相对成本权重，以及弃置回收比例。
- 计算结果是当前概率网格和成本假设下的估算。

### 核心功能3:频整器洗炼分析

- 五条副词条开满后，可锁定 1～4 条并分析其余词条重构后的升分概率与收益。
- 比较给定预算下的指定锁法和动态换锁方案（动态方案可根据每次重构后的实际状态重新选择后续锁法）。给定预算支持 0～6 枚。

### 截图识别副词条（试验版）

1. 在区域 2 的「截图识别」标签页点「设置识别区域」。工具会最小化，拖动框选可见游戏中的主词条、固定小词条和**完整副词条列表**，包含未解锁槽位。声骸名称、弃置／锁定标记、等级和经验栏可包含，也可从主词条行开始截图；这些页头不作为词条导入。松开保存，按 Esc 取消。
2. 回到简体中文开孔画面，点「截图识别」。识别结果会显示在当前标签页中，主词条和固定小词条前的图标误识别文字会被排除；“强化至……”行显示为“未开孔”，不要求选择词条或档位，也不参与回填和评分。仅按识别到的**已开副词条**数量回填 1～5 条；五条开满后可直接计算评分，零条已开仍不能回填。
3. Cost、主词条和固定小词条也从截图识别并一起回填。Cost 3/4 词条组合重叠时，以 0/5/10/15/20/25 级的线性数值对应关系判别；必要时可更正副词条类型或档位后点击「确认并回填」。识别值无法唯一判定 Cost 时会阻止回填，不会猜测。

只截取可见的窗口或无边框游戏画面。游戏位置、屏幕或缩放变化后请重新框选；不支持被遮挡、最小化或独占全屏的画面。透明度可调至 50%～100%，也可开启置顶；即使透明，工具与选区重叠时也会先最小化。

截图与识别文字只驻留本机内存，不上传、不自动保存。识别设置独立保存在应用旁的 `ocr-settings.json`。macOS 若提示未授权，请在「系统设置 → 隐私与安全性 → 屏幕与系统录音」授权当前应用（或启动源码版的应用），必要时重启。

试验目标是 Windows 11 x64 与 macOS Apple Silicon；已使用实机截图验证完整页头、仅等级栏、从主词条开始的三种裁剪，更多画面及跨平台准确率仍待验收。不提供实时识别、快捷键、自动应用或 Linux OCR 支持承诺。识别不成功时仍可手动录入。

### 权重方案管理

- 可以按副词条、Cost 1/3/4 主词条和固定小词条，分别设置权重。
- 【!!】不同的权重会影响评分计算和推荐结果。
- 修改后可保存当前方案或另存为新方案，也可重命名、删除和切换方案。
- 区域 1 标题右侧以不加粗的小字显示当前权重方案名，折叠后标注变为蓝色。
- 支持导出全部方案进行分享，导入时可以按方案 ID 去重。
- 方案数据保存在所在目录的 `weight-presets.json`

## 安装与启动

### 使用独立应用

Release提供了 Windows `.exe` 或 macOS `.app`，可直接运行，无需在目标电脑安装 Python：

- Windows：双击 `WWEcho声骸工作台.exe` 启动。若下载的是 EXE＋依赖目录版，请完整解压后运行，不要把 EXE 单独移动。
- macOS：在 Finder 中将 `WWEcho声骸工作台.app` 放到可写入的普通文件夹后打开。当前构建未进行 Apple Developer ID 签名和公证，macOS 可能显示安全提示。

首次启动会在应用所在目录创建权重方案库`weight-presets.json`；备份该文件即可保留自己的方案。

### 从源码运行

需要 Python 3.9 或更高版本。

Windows 可在项目目录双击 `run.bat`：脚本会创建项目虚拟环境并安装运行依赖（首次运行需要网络）。

macOS/Linux 用户在项目目录执行：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./run.sh
```

`run.sh` 使用项目 `.venv` 中的 Python；若尚未安装依赖，请先执行上面的安装命令。

仅在需要试用 OCR 时，用 **Python 3.9～3.12** 的项目虚拟环境执行 `python -m pip install -r requirements-ocr.txt`（Windows 使用 `.venv\Scripts\python.exe`，macOS 使用 `.venv/bin/python`）。此范围是当前候选引擎的试验环境约束，不改变手动功能的 Python 要求。

### 自行构建应用

含 OCR 的试验构建需要对应平台原生架构的 Python 3.9～3.12 和网络连接，以安装构建依赖：

- Windows 11 x64：`build-windows.bat` 默认构建两种产物。也可显式传入 `all`、`onefile` 或 `onedir`。
  - 整合 EXE：`dist/windows-onefile/WWEcho声骸工作台.exe`。PyInstaller 会在启动时解包运行资源。
  - EXE＋依赖目录：`dist/windows-onedir/WWEcho声骸工作台/`。分发时保留含 `_internal/` 的完整目录。
- macOS Apple Silicon：执行 `./build-macos.sh`，得到 `dist/WWEcho声骸工作台.app`。需用原生 arm64 Python；当前构建不含 Developer ID 签名或公证。

OCR 运行库、ONNX 模型和第三方许可信息随构建产物打包。运行时不下载模型，不需要系统 Python 或独立 OCR 工具。Windows 与 macOS 应分别在对应系统上构建，不能用其中一个产物的结果替代其他产物的验收。

构建前，项目根目录需有有效的 `weight-presets.json` 作为初始方案库模板；缺失时可先运行源码版 GUI 创建，或从已有方案库复制到该位置。

## 使用说明

1. **选择权重方案**：在顶部下拉框切换方案。可直接编辑权重；“保存修改”将修改保存到当前方案，“另存为”将保存到新方案。也可在“管理”菜单中重命名、删除方案。“导入”或“导出”方案能够自动去重。
2. **录入声骸和查看评分**：选择 Cost，再选择主词条；点击副词条名称勾选或取消，并在旁边选择档位。评分将会实时更新。
3. **开孔培养建议**：设置目标分数和材料成本参数。继续培养或弃置重开的建议会随着评分实时更新。
4. **频整器洗炼分析**：开满五条副词条后，在区域 4 锁定希望保留的词条，可以查看当前锁定下的概率和收益。也可以在方案表中点击想要的锁法，查看概率和收益。也可以设置频整器预算查看同预算下的方案收益。

关闭窗口或切换权重方案时，若当前方案有未保存修改，可选择保存、放弃或取消操作。建议定期将权重方案导出备份。

- `config/activation-costs.json`：培养经验、打孔器消耗、回收规则和默认成本权重。

## 运行测试

在已安装项目依赖的开发环境中，从项目根目录运行：

```bash
python -m unittest discover -s tests
```

OCR 解析和界面测试可单独运行 `python -m unittest tests.test_echo_ocr tests.test_echo_ocr_gui`。安装可选 OCR 依赖后，还会用 [实机截图](tests/sample.png) 验证三种页头裁剪；未安装引擎时仅跳过这项实机回归，合成文本测试仍可运行。
